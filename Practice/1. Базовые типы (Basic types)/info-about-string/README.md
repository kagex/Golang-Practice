# Вывод информации о строке

Представьте, что вы уже находитесь в функции `main`.

У нас уже создана переменная `str` с типом `string`. Необходимо вывести в одном `fmt.Println()` несколько значений:

- Значение переменной `str`.
- Количество байт строки `str`.
- Количество символов (рун) строки `str`.

## Примечание

- В функцию `fmt.Println()` можно передавать для вывода несколько значений, например: `fmt.Println(a, b, c)`. Дополнительные переносы строк ставить не нужно.
