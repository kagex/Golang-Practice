# Различные системы счисления

Нам необходимо разработать сервис, который будет представлять числа в разных системах счисления.

У нас уже существует переменная `num` в коде, которая содержит целое число. Нам необходимо вывести следующую строку (пример на примере числа 255 в переменной `num`):

```text
Запись числа 255 в разных системах счисления:
Десятичная: 255
Двоичная: 11111111
Восьмеричная: 377
Шестнадцатеричная: FF
```

## Примечание

- Вывод должен осуществляться через стандартные функции, вроде `fmt.Println()`.
- Будьте внимательны с пробелами в конце строк, их не должно быть.

## Тестовые данные

| № Теста | Входные данные | Выходные данные |
| :---: | :--- | :--- |
| 1 | `255` | Запись числа 255 в разных системах счисления:<br>Десятичная: 255<br>Двоичная: 11111111<br>Восьмеричная: 377<br>Шестнадцатеричная: FF |
| 2 | `875394` | Запись числа 875394 в разных системах счисления:<br>Десятичная: 875394<br>Двоичная: 11010101101110000010<br>Восьмеричная: 3255602<br>Шестнадцатеричная: D5B82 |
