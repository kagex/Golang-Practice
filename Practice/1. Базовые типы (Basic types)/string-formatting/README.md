# Обработка и анализ строки

Мы находимся в функции `main`. У нас уже есть переменная `message` типа `string`, необходимо выполнить следующие действия с данной строкой:

1. Удалить пробелы слева и справа от строки `message`, если такие имеются, и вывести полученную строку.
2. Преобразовать строку, полученную в пункте 1, в нижний регистр и вывести её.
3. Вывести `true`, если строка, полученная в пункте 2, начинается с букв `"go"`, в противном случае вывести `false`.

## Примечание

- Весь вывод должен осуществляться с помощью стандартных функций, вроде `fmt.Println()`.
