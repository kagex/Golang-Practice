# Преобразование int'ов

Необходимо написать код.

Предположим, что вы находитесь внутри функции `main`. У вас уже есть переменная с названием `i8` типа `int8`, которая содержит некоторое значение. Ваша задача — создать новую переменную `i` типа `int` и присвоить ей значение, которое хранится в переменной `i8`.

## Тестовые данные

| № Теста | Входные данные (значение `i8`) | Выходные данные |
| :---: | :---: | :--- |
| 1 | `8` | `Переменная i типа int, значение 8` |
| 2 | `-55` | `Переменная i типа int, значение -55` |
