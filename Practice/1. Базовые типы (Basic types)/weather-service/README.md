# Сервис погоды

Наша команда разрабатывает сервис погоды, который выполняет следующие действия:

Получает данные о погоде, включающие:

- `city` (`string`) — название города.
- `temp` (`int`) — температура в городе.
- `weather` (`string`) — текущее состояние погоды.

Сервис должен сформировать строку следующего формата (без кавычек), подставив соответствующие значения: `В городе [город] температура [температура]°C, [состояние].`

Полученную строку необходимо вывести в консоль.

## Тестовые данные

| № Теста | Входные данные | Выходные данные |
| :---: | :--- | :--- |
| 1 | `{"city":"Москва","temp":25,"weather":"солнечно"}` | `В городе Москва температура 25°C, солнечно.` |
| 2 | `{"city":"Санкт-Петербург","temp":21,"weather":"пасмурно"}` | `В городе Санкт-Петербург температура 21°C, пасмурно.` |
