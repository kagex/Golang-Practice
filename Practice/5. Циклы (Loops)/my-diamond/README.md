# Ромб из звездочек

Порисуем? Хочется увидеть ромбик в терминале, для этого необходимо создать функцию `printDiamond(n int)`, которая выводит текст `Мой бриллиант:`, а с новой строки ромб (смотри примеры), где `n` — это ребро ромба.

## Примечания

* В `n` всегда передаются корректные значения (больше или равное 1), проверку можно не делать.
* **В конце строк не должно быть лишних пробелов**, обратите на это внимание.
* Советую разделить вывод на две части — сначала выведите верхнюю часть ромба, потом уже подумаете, как вывести нижнюю часть, так будет проще.

---

### Тестовые данные

#### Тест 1

**Входные данные:** `1`

**Выходные данные:**

```text
Мой бриллиант:
#

```

---

#### Тест 2

**Входные данные:** `2`

**Выходные данные:**

```text
Мой бриллиант:
 #
# #
 #

```

---

#### Тест 3

**Входные данные:** `3`

**Выходные данные:**

```text
Мой бриллиант:
  #
 # #
#   #
 # #
  #

```
