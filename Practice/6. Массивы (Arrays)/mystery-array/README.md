# Загадочный массив

Необходимо реализовать функцию `CountVowelsInArray`, принимающую массив из 3 строк на русском языке. Функция должна вывести в консоль 3 целых числа через пробел, каждое число — это результат подсчета количества гласных букв в соответствующей строке исходного массива. Гласными буквами считаются: `а, е, ё, и, о, у, ы, э, ю, я` (в нижнем и верхнем регистре).

## Тестовые данные

| № Теста | Входные данные | Выходные данные |
| :---: | :--- | :--- |
| 1 | `["яблоко", "банан", "вишня"]` | `3 2 2` |
| 2 | `["Голанг", "Программирование", "Язык"]` | `2 7 2` |
| 3 | `["АЕИОУ", "кхм", ""]` | `5 0 0` |
