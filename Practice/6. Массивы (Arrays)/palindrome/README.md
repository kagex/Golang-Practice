# Палиндромный массив

Напишите функцию `isPalindrome`, которая принимает массив из 10 целых чисел и проверяет, является ли этот массив палиндромом. Палиндромом называется последовательность, которая читается одинаково с обеих сторон. Например, массив `[1, 2, 3, 2, 1]` является палиндромом, а массив `[1, 2, 3, 4, 5]` — нет.

Функция должна принимать массив из 10 целых чисел. Если принятый массив является палиндромом, необходимо вывести сообщение `"Это палиндром!"`, иначе `"Не палиндром!"`.

## Тестовые данные

| № Теста | Входные данные | Выходные данные |
| :---: | :--- | :--- |
| 1 | `[1, 2, 3, 4, 5, 4, 3, 2, 1, 1]` | `Не палиндром!` |
| 2 | `[1, 2, 3, 2, 1, 1, 2, 3, 2, 1]` | `Это палиндром!` |
| 3 | `[4, 2, 3, 3, 9, 9, 3, 3, 2, 4]` | `Это палиндром!` |
