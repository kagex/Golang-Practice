# Чудеса арифметики

Напишите функцию `printMagic`, которая принимает слайс целых чисел и выводит строку, похожую на массив, в консоль. Каждое выведенное число — это произведение всех остальных элементов исходного массива.

## Пример

Для входного массива `[1, 2, 3, 4]` программа должна вывести `[24, 12, 8, 6]`, где:

- Первый элемент `24` — это произведение `2 * 3 * 4`
- Второй элемент `12` — это произведение `1 * 3 * 4`
- Третий элемент `8` — это произведение `1 * 2 * 4`
- Четвертый элемент `6` — это произведение `1 * 2 * 3`

## Примечания

- Если на вход подается массив, который состоит из одного числа, необходимо вывести `[1]`, потому что других чисел для умножения нет, а произведение пустого набора равно единице.
- Обратите внимание (в тестовых данных можно заметить), что в функцию может быть передан и пустой слайс.

## Тестовые данные

| № Теста | Входные данные | Выходные данные |
| :---: | :--- | :--- |
| 1 | `[1, 2, 3, 4]` | `[24, 12, 8, 6]` |
| 2 | `[5, 6, 7, 1, 1]` | `[42, 35, 30, 210, 210]` |
| 3 | `[2, 0, -3]` | `[0, -6, 0]` |
| 4 | `[]` | `[]` |
| 5 | `[5]` | `[1]` |
