# Пересечения

Необходимо реализовать функцию `intersectSlices`, которая будет принимать два слайса целых чисел, отсортированных по возрастанию значения. Возвращаться должен новый слайс, содержащий все пересечения этих слайсов (тоже в отсортированном порядке), а также ошибку.

Если один из переданных слайсов равен `nil`, функция должна возвращать ошибку с сообщением: `slices cannot be nil`.

Если вы решили решить задачу с помощью цикла, вложенного в другой цикл (сравнивая каждый элемент первого слайса с каждым элементом второго), вы молодец. Но такое решение будет работать очень медленно на больших массивах.

Здесь есть один нюанс, на который стоит обратить внимание: слайсы уже отсортированы по возрастанию. Это нам дает возможность использовать популярный алгоритмический подход, который называется **"Два указателя"**.

## Логика алгоритма

1. Создайте две переменные-индекса (например, `i` и `j`), которые будут играть роль "указателей". Изначально они оба равны `0` (указывают на первые элементы обоих слайсов).
2. Запустите цикл, который будет работать до тех пор, пока хотя бы один из указателей не выйдет за границы своего слайса.
3. На каждом шаге цикла сравнивайте текущие элементы: `slice1[i]` и `slice2[j]`.
   - Если `slice1[i] < slice2[j]`: первый элемент меньше. Так как массивы отсортированы, мы можем найти совпадение, только если сдвинем указатель в первом массиве вперед: `i = i + 1`.
   - Если `slice1[i] > slice2[j]`: наоборот, второй элемент меньше. Сдвигаем указатель во втором массиве: `j = j + 1`.
   - Если они равны: это как раз то, что мы искали, мы нашли пересечение. Добавляем это число в результирующий слайс и сдвигаем оба указателя вперед: `i = i + 1` и `j = j + 1`.

## Пример работы алгоритма

Для слайсов `[1, 3, 5]` и `[2, 3, 4]`:

- **Шаг 1:** `1 < 2` → увеличиваем `i`
- **Шаг 2:** `3 > 2` → увеличиваем `j`
- **Шаг 3:** `3 == 3` → сохраняем `3`, увеличиваем и `i`, и `j`

> **Важно:** Только не забудьте перед началом цикла проверить оба слайса на `nil` и вернуть ошибку, как указано в условии.

## Примечание

- Элементы слайсов могут повторяться, имейте это в виду.

## Тестовые данные

| № Теста | Входные данные | Выходные данные |
| :---: | :--- | :--- |
| 1 | `{"slice1": [1, 2, 3, 4, 5], "slice2": [3, 4, 5, 6, 7]}` | `[3 4 5]` |
| 2 | `{"slice1": [1, 3, 5, 7], "slice2": [2, 4, 6, 8]}` | `[]` |
| 3 | `{"slice1": null, "slice2": [1, 2, 3]}` | `error: slices cannot be nil` |
| 4 | `{"slice1": [], "slice2": []}` | `[]` |
| 5 | `{"slice1": [-3, -2, -1, 0, 1, 2, 3], "slice2": [-2, 0, 2, 4, 6]}` | `[-2 0 2]` |
