# Вставь туда, вставь сюда...

Необходимо реализовать функцию `PlayWithSlice`, которая будет принимать слайс целых чисел и выполнять с ним несколько операций, возвращая новый слайс целых чисел:

## Логика работы функции

1. **Клонирование слайса:** Создайте новый слайс, который будет являться клоном переданного слайса. Все дальнейшие операции должны выполняться только с клоном.
2. **Вставка числа 100:** Найдите первое значение с конца клона, которое больше `10`. После этого значения вставьте число `100`. Если такого значения не найдено, этот шаг можно пропустить.
3. **Вставка числа 500:** Если сумма всех чисел в текущем клоне больше `100`, добавьте число `500` в конец слайса.
4. **Вставка числа 1000:** Если в оригинальном слайсе четных чисел больше, чем нечетных, вставьте число `1000` в начало клона слайса.

Функция должна вернуть модифицированный слайс.

## Дополнительные указания

- Обратите внимание на то, что слайсы в Go передаются по ссылке, поэтому вам нужно создать новый слайс, чтобы избежать изменения оригинального.
- Убедитесь, что ваша функция корректно обрабатывает пустые слайсы и слайсы, не содержащие чисел, удовлетворяющих условиям.
