# Поиск максимального элемента в слайсе

Вам необходимо реализовать функцию `Max`, которая будет находить максимальный элемент в слайсе целых чисел. Функция должна принимать слайс в качестве аргумента и возвращать максимальное значение и возможную ошибку. Если слайс равен `nil` или пуст, функция должна возвращать ошибку с сообщением: `slice is nil or empty`.

## Тестовые данные

| № Теста | Входные данные | Выходные данные |
| :---: | :--- | :--- |
| 1 | `[1, 3, 2]` | `3` |
| 2 | `[5, 7, 2, 8]` | `8` |
| 3 | `[-1, -5, -3]` | `-1` |
| 4 | `[1, 5]` | `5` |
| 5 | `[]` | `error: slice is nil or empty` |
| 6 | `[10]` | `10` |
| 7 | `null` | `error: slice is nil or empty` |
