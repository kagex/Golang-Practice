# Отзеркаливание матрицы

Напишите функцию `mirrorMatrix`, которая принимает двумерный слайс целых чисел и возвращает новый двумерный слайс.

В возвращаемом слайсе каждая строка должна быть отзеркалена по горизонтали, то есть элементы внутри каждой строки должны располагаться в обратном порядке.

Исходный слайс не должен быть изменен.

## Примечание

- Двумерный слайс, как и слайсы внутри него, могут иметь разную длину, а также могут быть пустыми.
