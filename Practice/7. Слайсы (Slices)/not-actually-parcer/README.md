# Парсим URL-параметры

Устроился как-то раз программист Паша на работу системным администратором, да захотел порядок в логах навести. Логов так много, что с ума можно сойти, помогите Паше... Ему очень пригодилась бы функция, которая может вытащить из URL имя пользователя, которое передается в GET-параметре.

## Условие задачи

Необходимо создать функцию `GetUserParam`, которая будет принимать строку с записанным в ней URL. Нужно вернуть из функции строку, в которой будет записано значение для параметра `user`.

Данный параметр `user` может быть в середине, в конце списка GET-параметров, а может и вовсе отсутствовать. Если параметра `user` нет, необходимо вернуть строку с текстом `not found`.

## Пример

Если в функцию будет передано значение:  
`https://site.ru/page?user=pavel&id=12345&limit=20`

Функция должна найти GET-параметры (это часть после знака `?`), найти среди параметров значение под ключом `user` и вернуть это значение. В данном примере мы должны вернуть значение `pavel`.

## Примечание

- Для решения этой задачи есть готовые пакеты для парсинга URL, однако желательно использовать базовые операции со строками (включая те, что есть в пакете `strings`).
- Обратите внимание: если значения у параметра `user` нет (например, `?user=`), то необходимо вернуть строку `not found`, как и в случае полного отсутствия ключа.
- Если в URL присутствует 2 и более параметра `user`, то необходимо вернуть **первое непустое** значение. Если все значения окажутся пустыми, то понадобится вернуть `not found`.
