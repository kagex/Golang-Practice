# Замена четных значений

Напишите функцию `replaceEvenOnEvenIndices`, которая принимает двумерный слайс целых чисел и возвращает новый двумерный слайс.

## Логика работы функции

- В возвращаемом слайсе должны быть те же значения, что и в исходном.
- Однако все четные числа, расположенные на четных индексах внутри своих слайсов (включая индекс `0`), должны быть заменены на `0`.

## Важный нюанс

Функция должна выполнять **глубокое копирование** (deep copy). Это означает, что нам:

- **Запрещено** изменять переданный слайс.
- Внешний слайс и абсолютно все внутренние слайсы в возвращаемом результате должны быть выделены в памяти заново. Поверхностное копирование элементов (только для внешнего слайса) тесты не пройдет.

## Тестовые данные

| № Теста | Входные данные | Выходные данные |
| :---: | :--- | :--- |
| 1 | `[`<br>&nbsp;&nbsp;`[1, 2],`<br>&nbsp;&nbsp;`[5, 6, 7, 8],`<br>&nbsp;&nbsp;`[9, 10, 11]`<br>`]` | `[`<br>&nbsp;&nbsp;`[1, 2],`<br>&nbsp;&nbsp;`[5, 6, 7, 8],`<br>&nbsp;&nbsp;`[9, 10, 11]`<br>`]` |
| 2 | `[`<br>&nbsp;&nbsp;`[1, 2, 3],`<br>&nbsp;&nbsp;`[],`<br>&nbsp;&nbsp;`[7, 8, 9, 22, 48],`<br>&nbsp;&nbsp;`[10, 11]`<br>`]` | `[`<br>&nbsp;&nbsp;`[1, 2, 3],`<br>&nbsp;&nbsp;`[],`<br>&nbsp;&nbsp;`[7, 8, 9, 22, 0],`<br>&nbsp;&nbsp;`[0, 11]`<br>`]` |
