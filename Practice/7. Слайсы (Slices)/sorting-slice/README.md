# Сортируй - не сортируй, все равно получишь

Необходимо реализовать функцию `magicSort`, которая принимает двумерный слайс целых чисел и сортирует его по следующим критериям:

## Логика работы функции

1. **Внешний слайс** должен быть отсортирован по возрастанию суммы чисел в каждом внутреннем слайсе. Если слайсы имеют одинаковую сумму, то они должны быть в том же порядке, что и были (стабильная сортировка).
2. **Каждый внутренний слайс** должен быть отсортирован в порядке убывания, при этом четные числа должны идти перед нечетными. Ноль идет перед всеми числами.

## Примечание

- Убедитесь, что ваша функция корректно обрабатывает пустые слайсы.
- Обратите внимание: функция `magicSort` не должна ничего возвращать или выводить, она должна только отсортировать слайс.
