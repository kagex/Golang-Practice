# Инвертирование мапы

Вам необходимо реализовать две функции: первая — `invertMap`, которая будет инвертировать входную `map`, вторая — `printMap`, которая будет выводить данные, полученные от `invertMap`, в правильном формате.

## Описание функций

- Функция `invertMap` должна принимать `map` типа `map[string]int` и возвращать новую `map` типа `map[int][]string`. В новой `map` ключами будут значения из исходной `map`, а значениями — срезы ключей, которые соответствуют этим значениям.
- Функция `printMap` должна принимать то, что возвращает функция `invertMap`, то есть функция `printMap` должна принимать `map[int][]string` и выводить эти данные в определенном формате (смотри примеры).

## Пример

Функция `main` уже реализована, можете считать, что она выглядит так:

```go
func main() {
  m := map[string]int{
    "banana":     2,
    "apple":      1,
    "grapefruit": 3,
    "cherry":     1,
  }
  invertedMap := invertMap(m)
  printMap(invertedMap)
}
```

## Пояснение

Из функции `main` (она уже реализована за вас) передаются в `invertMap` следующие данные:

```go
map[string]int{
  "banana":     2,
  "apple":      1,
  "grapefruit": 3,
  "cherry":     1,
}
```

Функция `invertMap` должна вернуть следующие данные (порядок ключей в `map` и значений в слайсах может отличаться):

```go
map[int][]string{
  2: {"banana"},
  1: {"apple", "cherry"},
  3: {"grapefruit"},
}
```

Далее функция `main` вызовет функцию `printMap`, передав туда значение, полученное от `invertMap`. Функция `printMap` должна вывести следующее сообщение:

```text
{
  1: ["apple", "cherry"],
  2: ["banana"],
  3: ["grapefruit"],
}
```

> **Порядок ключей строгий** — он должен быть по возрастанию. Порядок строк (значений в слайсах) должен быть в алфавитном порядке.

## Примечание

- Советую сначала реализовать `invertMap`, потом уже `printMap`. Не стоит пытаться сделать сразу все.
