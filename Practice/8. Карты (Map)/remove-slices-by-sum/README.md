# Удаление по сумме элементов

Необходимо написать функцию `RemoveSlicesBySum`, которая принимает на вход `map` типа `map[string][]int` и удаляет из этой `map` все слайсы, сумма элементов которых превышает `6`.

## Примечание

- Функция `main` уже реализована, она вызывает функцию `RemoveSlicesBySum`, после чего выводит `map` в консоль.
- Функция не должна ничего возвращать, только менять `map`.

| № Теста | Входные данные | Выходные данные |
| :---: | :--- | :--- |
| 1 | `{`<br>&nbsp;&nbsp;`"a": [1, 2, 3],`<br>&nbsp;&nbsp;`"b": [1, 1, 1, 1],`<br>&nbsp;&nbsp;`"c": [20, 30, -100]`<br>`}` | `{`<br>&nbsp;&nbsp;`"a": [1, 2, 3],`<br>&nbsp;&nbsp;`"b": [1, 1, 1, 1],`<br>&nbsp;&nbsp;`"c": [20, 30, -100]`<br>`}` |
| 2 | `{`<br>&nbsp;&nbsp;`"a": [7],`<br>&nbsp;&nbsp;`"b": [4, 3],`<br>&nbsp;&nbsp;`"c": [10, 1, 2]`<br>`}` | `{}` |
