# Группировка данных

В этом задании вам необходимо создать структуру и функцию, которые будут использоваться для представления и создания события.

## Структура `Event`

Первым делом, необходимо создать тип структуры `Event`, которая будет содержать поля:

- `Title` (тип: `string`) — название события.
- `Date` (тип: `string`) — дата события.
- `Location` (тип: `string`) — место проведения события.

## Функция `createGoEvent`

После того как создадите тип `Event`, необходимо будет создать функцию `createGoEvent`, которая создаст и вернет экземпляр структуры `Event` со следующими данными:

- **Title:** `"День рождения Golang"`
- **Date:** `"10 ноября 2009"`
- **Location:** `"GoogleLand"`
